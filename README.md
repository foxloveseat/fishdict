# Дневник рыбака
Простой, удобный и быстрый дневник записи рыболовных поездок на фреймворке Gin

# Установка
1. Установка go (язык программирования)
2. Скачать папку templates
3. Скачать бинарник со страницы релиза
4. Запустить в одной папке с templates
5. Пользоваться, открыв в браузере localhost:6767)
